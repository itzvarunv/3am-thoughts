# 3am-thoughts

A dumping ground for bizarre ideas that show up uninvited — mostly at 3am, mostly in dreams, mostly half-formed.

## What goes here

Any idea that:
- arrives out of nowhere (a dream, a half-asleep thought, a shower thought that won't let go)
- feels either brilliant or completely dumb, often at the same time
- probably won't survive contact with rigor, but is worth writing down before it evaporates

Math, physics, random systems, whatever — no topic restriction. The only qualifier is *it sounded logical at 3am*.

## Format

Each idea gets its own markdown file. Loose structure, roughly:

1. **The idea** — what it was, as close to the original half-asleep version as possible
2. **Where it goes** — how the reasoning developed when actually pushed on
3. **Where it breaks** — the point it stopped holding up (there's almost always one)
4. **What it's secretly close to** — if it turns out to overlap with something real (it often does)

## Why bother

Most of these won't be "correct." That's not the point. The point is:
- some of them accidentally rediscover real, established ideas from scratch, which is a decent sign the instinct behind them isn't random
- writing down *where exactly* something breaks is more useful than remembering "I had a weird idea once"
- future-me gets to see the pattern of what kinds of dumb ideas keep showing up

No idea is too bizarre to log. If it felt real enough to want to check, it's real enough to belong here.
